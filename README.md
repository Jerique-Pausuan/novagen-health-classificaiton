# novagen-health-classificaiton
Predicts patient health status using Scikit-Learn, benchmarked 6 algorithms: Logistic Regression, Random Forest, K-Nearest Neighbors, Support Vector Machine (SVC), Gradient Boosting, and a Voting Ensemble
The tuned RBF-kernel SVC model delivered top performance with - 93.56% accuracy and 94.06% recall
